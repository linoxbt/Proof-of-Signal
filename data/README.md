# Data

Download scripts only. Raw datasets never go in git (`data/raw/` and `data/cache/` are ignored). Sources and licences are in the spec's "Data sources and licences" table: INEC PU locator, CredibleVoteNG, OpenCellID (CC BY-SA 4.0), Ookla open data (CC BY-NC-SA 4.0, non-commercial), GRID3, Copernicus DEM GLO-30.
